# Task 3 — Our outdoor image dataset

Collect photographs for the simple person / no-person CNN experiment.

## Required folders

Put the team's real photographs into this structure:

```text
images/
  train/
    no_person/
    person/
  validation/
    no_person/
    person/
```

- `person/`: outdoor photographs containing at least one visible person.
- `no_person/`: outdoor photographs with no people.
- `train/`: images used to train the CNN.
- `validation/`: different images used to check the trained CNN.

Use JPG or PNG images. Keep the original photographs until the team has agreed which images belong in each split. Avoid putting near-identical frames or photographs of the same scene in both training and validation folders.

The repository currently contains empty folder placeholders only. Add the actual photographs after the team collects them outside. Obtain appropriate consent before publishing identifiable people's photographs in this public repository.
